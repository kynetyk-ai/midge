# Acknowledgements

## pi-mono

This project began as a Python port of [`pi-mono`](https://github.com/badlogic/pi-mono), a TypeScript agent harness by [Mario Zechner](https://github.com/badlogic). pi-mono is MIT-licensed.

Thank you to Mario Zechner for shipping pi-mono in public.

## Core dependencies

The harness leans on a small set of well-maintained Python libraries:

- [`openai`](https://github.com/openai/openai-python) — async OpenAI-compatible client.
- [`pydantic`](https://docs.pydantic.dev/) — schema generation and message validation.
- [`mistune`](https://mistune.lepture.com/) — Markdown rendering for the HTML exporter.
- [`pygments`](https://pygments.org/) — code highlighting in the HTML exporter.
- [`textual`](https://github.com/Textualize/textual) — the TUI.
